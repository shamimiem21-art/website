# 🌿 HabitFlow - Production Habit & Daily Task Tracker

HabitFlow is a modern, responsive, nature-inspired web application designed for personal habit formation, daily task tracking, analytical reporting, and productivity growth.

---

## 🌟 Key Features

1. **Multi-User Account System & Quick Demo Login**:
   - Private user accounts with separate dashboards.
   - **One-Click Demo User Login** (`demo@habitflow.com`) & **One-Click Admin Login** (`admin@habitflow.com`).

2. **Personal Dashboard**:
   - Live Productivity Score & Current/Longest Streaks.
   - **Today's Habits & Tasks Checklist** directly in Dashboard.
   - **365-Day Calendar Heatmap** (GitHub-style activity grid).
   - Achievement Badges & Broadcast System Announcements.

3. **Daily Task Tracker Matrix**:
   - 7-Day Completion Matrix (Sun - Sat).
   - **HTML5 Drag-and-Drop Reordering**.
   - Categories, Priority Tags (High, Medium, Low), and Archive toggle.

4. **Statistics & Interactive Analytics**:
   - Chart.js integration for Daily Completion Line Charts, Category Doughnuts, and Weekly Trend Bars.

5. **Analytical Performance Reports**:
   - Dedicated Weekly & Monthly reports with AI Growth Suggestions, Print View, and Chart PNG Download.

6. **Calendar View & Browser Reminders**:
   - Interactive monthly calendar with day details modal.
   - Custom scheduled habit reminders.

7. **Administrative Terminal**:
   - User Management, Category Manager, Broadcast Announcements, Feature Flags, and Real-time System Logs.
